# .github

Arquivos de comunidade padrão da organização **ImentSoftwares**.

Os arquivos deste repositório são aplicados automaticamente a todos os repositórios da org que não tenham versões próprias:

| Arquivo | Função |
|---|---|
| [`profile/README.md`](profile/README.md) | Página de perfil em github.com/ImentSoftwares |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Fluxo de branches, commits e PRs |
| [`pull_request_template.md`](pull_request_template.md) | Modelo de Pull Request |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE) | Formulários de bug e de funcionalidade |
| [`SECURITY.md`](SECURITY.md) | Como reportar vulnerabilidades |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Código de conduta |

Para sobrescrever algum desses arquivos num repositório específico, crie o arquivo com o mesmo nome dentro dele.
