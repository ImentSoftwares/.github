# Iment Softwares

Desenvolvimento de software sob medida — web, mobile e automações.

### Como trabalhamos

- **Código revisado:** toda mudança entra na `main` via Pull Request com revisão.
- **Commits padronizados:** seguimos [Conventional Commits](https://www.conventionalcommits.org/pt-br/).
- **Versionamento:** [SemVer](https://semver.org/lang/pt-BR/) com releases e changelog.
- **Segurança desde o início:** Dependabot e secret scanning ativos nos repositórios.

### Contato

Encontrou um problema de segurança? Veja nossa [política de segurança](https://github.com/ImentSoftwares/.github/blob/main/SECURITY.md).
