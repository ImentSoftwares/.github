# Política de segurança

## Como reportar uma vulnerabilidade

**Não abra uma issue pública** para relatar falhas de segurança.

Use o recurso **"Report a vulnerability"**, na aba **Security** do repositório afetado. O relato fica privado entre você e os mantenedores.

Inclua, se possível:

- Descrição da vulnerabilidade e impacto
- Passos para reproduzir
- Versão, ambiente ou URL afetados
- Sugestão de correção (opcional)

## O que esperar

| Etapa                         | Prazo           |
|-------------------------------|-----------------|
| Confirmação de recebimento    | até 3 dias úteis |
| Avaliação inicial             | até 7 dias úteis |
| Correção de falhas críticas   | o mais rápido possível |

Pedimos que a divulgação pública só ocorra depois que a correção for publicada.

## Versões suportadas

Corrigimos vulnerabilidades apenas na versão mais recente de cada projeto, salvo indicação contrária no README do repositório.
